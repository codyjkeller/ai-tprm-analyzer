# Legacy demo scripts

These are the original demonstration scripts. They are kept for reference and
are **not** used by the tool.

They do not analyze real input: `analyze_vendor.py` checks a sample sentence
that is written inside the script, and `analyzer.py` scores a vendor that is
written inside the script. Neither calls an AI model.

Use `python -m tprm analyze <vendor file>` instead. See the main README.
